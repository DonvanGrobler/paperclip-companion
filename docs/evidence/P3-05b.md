## Summary

Add an unwired main owner that reserves one submitted run, binds its current
consent/destination/session/target/policy incarnation, invokes mock capture once,
rechecks fresh prerequisites before one dispatch and clears owned image views.
Cancellation/timeout/revocation settles promptly but retains the busy slot and
still-borrowed private view until adapters actually finish. Fixed outcomes report
whether dispatch had started. There is no retry or silent fallback.

Files changed: src/main/screen-request.ts; tests/unit/screen-request.test.ts;
ADR 0026; this evidence; one anchored DEVELOPMENT_PLAN.md milestone row.
Production entry point, renderer, preload, provider and native source are unchanged.

## Security/privacy/license changes

Direct review confirms the active slot is reserved before callbacks, valid run IDs
are consumed, and no cached eligibility survives capture. Fresh trusted policy
and the exact consent grant must still agree immediately before dispatch. Ticket
identity binds returned bytes to that request; it does not prove native origin.
Registry changes must publish a new policy incarnation and notify invalidation;
real adapters must pin actual routing and revalidate after internal awaits.

Recognized exclusively transferred source views clear even on invalid output;
private dispatch bytes stay valid for the borrower until actual completion, then
clear on all paths. Late results are discarded. Shared storage is rejected. Stop
reports dispatchStarted accurately; bytes already delivered cannot be retracted.
No claim of hard preemption, total native-memory bounds or forensic erasure.

No production import, IPC expansion, OS permission, credential/auth flow, image
storage, logging, telemetry, network implementation, new dependency or artwork.
License inventory remains unchanged; no SDK/sample source copied. Existing binary
notices/native redistribution obligations remain separate from npm metadata.

Quality gate: component **in review**; G3 remains open and production capture
