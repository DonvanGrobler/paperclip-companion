## Security/privacy/license review and quality gate

Direct review: all context handles are trusted main-owned synthetic/internal
values, copied from strict data descriptors. Invalid or unsupported context drops
old authority. Revocation clears state before abort notification; reentrant
acceptance/update is rejected, withdrawal/disposal still wins. An old grant fails
identity revalidation after an account returns or fresh consent is granted.

The renderer preview is not migrated into consent. A future trusted action adapter
must show real destination/account/disclosure/privacy policy and validate an
explicit choice. Auth loss/session replacement must be published by its main
owner; the component cannot discover them. A grant cannot replace independent
request/target/exclusion/Never/permission/vision checks or single-use orchestration.
Abort is cooperative, does not erase another owner's bytes and cannot retract
already delivered data. No persisted consent or forensic erasure claim.

No new dependency, permission, copied SDK/sample code, art, files, telemetry,
network egress, IPC or settings migration. Existing notices and native binary
redistribution review remain separate; npm metadata is not whole-app clearance.

Quality gate: this component is in review; **G3 remains open**. OD-02 external
identity/selection, real consent/controls, live capture, physical displays and the
