## Security, licensing and remaining blocker

Main-only encoder remains unwired. It accepts exact bounded byte views and
explicit alpha mode; no source/identity/consent/provider assertion is granted
authority by conversion. Caller retains original BGRA ownership; private
scanlines and compressed bytes clear after actual compression completion.
Timeout/cancellation returns no image while retaining busy state until callback,
preventing a queue of abandoned work. Returned PNG ownership transfers once;
future orchestration must clear/recheck policy before dispatch. This is not
hard preemption or forensic erasure of native/allocator copies.

Only critical PNG chunks are emitted; no prompt, path, title, account, target,
EXIF/text/time or other incidental metadata. No logging, image files/artifacts,
network, new renderer IPC/permission, dependency, asset or copied sample code.
Existing Node/Electron/zlib binary licensing/notices remain; no release/native
redistribution clearance is inferred from npm metadata.

External identity research did not resolve OD-02: WGC's reviewed item API has
no reverse HWND/PID getter; SetProp's documented pre-destruction cleanup cannot
be guaranteed for the independently closing foreign-window proposal. No marker,
hook/injection, elevation or weaker authorization is introduced. ADR 0024 records
the finding. Independent conversion proceeds under plan section 4; capture and
phase promotion stay blocked by existing requirements.
